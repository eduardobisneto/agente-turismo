# Aventura Organizada

Site institucional da Aventura Organizada, agência de turismo de aventura com roteiros pelo Brasil.

## Desenvolvimento

Requer [Bun](https://bun.sh).

```sh
bun install
bun run dev
```

## Build

```sh
bun run build
```

## Docker

```sh
docker compose build --no-cache
docker compose up
```

## Stack

- TanStack Start
- TypeScript
- React
- Tailwind CSS
